## About the Game
The theme of the hackathon was **time glitch** so we decided to make a game in which you and your pet dog get transported back in time and have to use the ability to age or deage objects to solve puzzles and save your pet from a certain prince and get back to the present!

## How We Built It

### What we used
- **Art:** Aseprite, itch.io
- **Game Engine:** Godot 4.4
- **Programming Language:** GDScript

### Development Process

#### Day 1 (24 hours)
- **Hours 0-4:** Brainstorming and concept finalization
- **Hours 4-16:** Most sprites and enviorment assets, basic player controller
- **Hours 16-24:** Started adding interactive objects and working on implementing story

#### Day 2 (24 hours)  
- **Hours 24-32:** Polish gameplay
- **Hours 32-40:** UI/UX improvements, audio and cutscenes
- **Hours 40-46:** Final testing and optimization (also panic)
- **Hours 46-48:** Presentation preparation and submission


### Challenges
1. **Git problems:** We encountered multiple merge conflicts
   - We learned how to properly manage a project as a team using git

2. **Teamwork:** 
   - Split the game into 3 main scenes and assigned a person to each one in order to work in paralel while also avoiding conflicts, leading to a faster development process

3. **Time Management:**
   - We prioritised making the beginning and the end of the game to ensure a finished product by the end of the hackathon

## How to Build
### Prerequisites
- [Godot 4.4](https://godotengine.org/download/archive/4.4-stable/")

### Installation (Windows only)
```bash
# Clone the repository
git clone https://github.com/denis0bej/appsters.git
```

### Opening the project
- Open Godot 4.4
- Press **"Import"** in the top right corner
- Select the directory using the **"Browse"** button and click **""Import"**
- Select the project in the project list and click **"Edit"**

### Building
- Open the project in edit mode if you haven't already
- Open the **"Project"** menu in the top left
- Click on **"Export"**
- Select the platform (Windows)
- Click on **"Export Project..."**
- Select the destination and click **"Save"**
